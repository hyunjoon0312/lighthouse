# Lighthouse

macOS에서 사진을 정리하고 선별한 뒤 RAW를 보정해 JPEG로 내보내는 로컬 데스크톱 앱입니다. Panasonic LUMIX S9의 RW2를 주 대상으로 개발했습니다.

## 실행

현재 Mac에서는 `dist/Lighthouse.app`을 더블클릭해 실행하면 됩니다. **사진 가져오기**로 시작하세요. 외부 패키지나 계정은 필요하지 않습니다.

소스에서 빌드하려면 macOS 15 이상과 Swift 6을 포함한 Xcode 또는 Command Line Tools가 필요합니다.

```sh
./scripts/build-app.sh
open dist/Lighthouse.app
```

개발 중에는 `swift run Lighthouse`로 실행할 수 있습니다. `Package.swift`를 Xcode에서 열어 개발할 수도 있습니다. 현재 번들은 로컬 실행용 ad-hoc 서명을 사용하며 배포용 공증은 포함하지 않습니다.

## 사용 흐름

1. **사진 가져오기**에서 RW2·JPEG·HEIC·PNG·TIFF 파일이나 사진 폴더를 선택합니다. 하위 폴더도 탐색하며 같은 경로를 반복 가져오면 중복을 제외합니다. 메모리 카드는 **카드에서 복사…**(⇧⌘O)를 쓰세요. 원본은 카드에 두고 사진을 `~/Pictures/Lighthouse/연도/연-월-일`(위치 변경 가능)로 복사한 뒤 가져오므로 카드를 빼도 계속 편집할 수 있습니다. 같은 카드를 다시 가져오면 이미 복사한 사진은 건너뜁니다.
2. 그리드에서 사진을 고르고 별점과 선택·제외 표시를 붙입니다. 위쪽의 **표시 후 다음 사진**을 켜면 키로 표시할 때마다 다음 사진으로 넘어갑니다. 위쪽 정렬 메뉴로 촬영 시각·파일 이름·별점 높은 순으로 볼 수 있고(같은 값끼리는 촬영 시각 순), 그리드에서는 선택 줄의 슬라이더로 썸네일 크기를 바꿉니다. 오른쪽 패널에서 키워드(쉼표로 구분)와 설명을 붙이면 검색으로 찾을 수 있고 JPEG로 내보낼 때 IPTC 키워드·설명으로 들어갑니다. 여러 장을 골랐으면 **선택한 N장에 키워드 추가**로 한 번에 붙입니다. 별점·표시처럼 ⌘Z로 되돌릴 수 있습니다. 사진 보기에서 사진을 클릭하면 그 위치를 100%로 확대하고, 다시 클릭하면 화면 맞춤으로 돌아옵니다. **원본 위치**별로 찾아보거나 **내 폴더**를 만들어 사진을 묶습니다. [폴더와 원본 보존](docs/photo-folders.md)을 참고하세요. RAW+JPEG로 찍은 사진은 위쪽 **RAW+JPEG 한 장으로**가 켜져 있으면 RAW만 보입니다(JPEG는 카탈로그에 남고 끄면 다시 보입니다). **연속 촬영**에서는 1초 이내에 이어 찍은 컷을 묶어 보고, 선명도와 얼굴 품질로 묶음마다 추천 컷을 고를 수 있습니다. 자세한 내용은 [연속 촬영 고르기](docs/bursts.md)에 있습니다.
3. 사진 보기에서 노출, 색온도·틴트, 대비, 하이라이트·섀도, 명료도, 생동감·채도, 선명도, 비네팅과 RGB 곡선·색상 범위·필름 입자를 조절합니다. RAW는 노이즈 감소·렌즈 보정·하이라이트 복구도 조절할 수 있습니다. 자유 크롭과 수평 보정으로 구도를 정합니다. [고급 보정 안내](docs/advanced-editing.md)를 참고하세요.
4. **부분 보정**에서 피사체·배경을 자동 선택하거나, 브러시로 칠하거나, 직선·원형 그라데이션을 놓아 해당 부분의 노출·대비·색온도·채도·명료도를 조절합니다. 지우개, 경계 부드럽게, 여러 영역, 마스크 표시를 지원합니다. **복구**에서는 작은 잡티를 복구하거나 직접 고른 소스를 복제합니다.
5. 같은 사진을 다르게 보정하려면 **가상 사본 만들기**(⌘')로 파일 복제 없이 보정만 따로 가진 사본을 만듭니다. **전체 보정 → 프리셋 → 현재 보정 저장…**으로 자주 쓰는 보정(전체 보정·LUT·구도 중 선택)을 이름 붙여 저장하고, 현재 사진이나 선택한 여러 장에 한 번에 적용합니다. **가져올 때 적용**을 정하면 새로 가져오는 사진에 자동으로 적용합니다.
6. **전체 보정 → LUT → .cube 추가…**로 여러 LUT를 보관하고 목록에서 골라 적용합니다. 강도는 0–100%로 조절합니다. [LUT 사용 안내](docs/lut.md)에서 형식과 백업 방법을 확인할 수 있습니다.
7. **참조 사진 색감 맞추기…**에서 원하는 사진의 톤·색 분포를 근사하고 결과를 적용하거나 새 LUT로 보관합니다. **S9용 .cube 내보내기…**로 카메라 지원 규격의 파일을 만들 수 있습니다. [참조 색감과 S9 안내](docs/reference-match.md)를 읽어주세요.
8. 체크 버튼·⌘클릭·⇧클릭으로 사진을 여러 장 선택한 뒤 **일괄 적용…**에서 보정 범위를 고릅니다. **선택한 N장에 LUT 적용**은 LUT만 복사합니다. [여러 사진 편집 안내](docs/batch-editing.md)에 자세한 동작을 설명했습니다.
9. 비교 모드에서는 기준 사진과 다른 사진을 나란히 보며 선별합니다. 기준 사진은 보정한 모습으로 보여 가상 사본끼리도 비교할 수 있고, **기준 원본 보기**로 보정 전 모습으로 바꿀 수 있습니다. 화면 맞춤과 100% 보기를 전환할 수 있습니다.
10. **JPEG 내보내기**에서 실제 압축 미리보기와 파일 크기를 확인하고 현재 사진, 선택한 사진 또는 현재 필터 결과를 저장합니다. 긴 변과 품질을 선택할 수 있고 파일명이 겹치면 접미사를 붙입니다. 여러 장에서는 대표 사진 한 장의 크기를 표시하며, 진행 중에 **중지**하면 처리 중인 한 장까지만 저장합니다. 촬영일·카메라·렌즈·노출 정보는 원본에서 옮기며, 위치(GPS)는 **위치(GPS) 정보 포함**을 켠 경우에만 넣습니다. 저장 폴더는 다음에 열 때 기억합니다. 파일 이름은 `{원본}`·`{날짜}`·`{시간}`·`{번호}`·`{사본}`으로 규칙을 정하고(가상 사본은 `{사본}`이 없어도 `-사본1`이 붙습니다), 글자 워터마크(위치·크기·불투명도)를 넣을 수 있습니다. 자주 쓰는 설정은 **프리셋 → 현재 설정 저장…**으로 보관하며 블로그용(긴 변 2048px·85%)과 원본 크기(95%) 프리셋이 기본으로 있습니다.

| --- | --- |
| ⌘O | 사진·폴더 가져오기 |
| ⇧⌘O | 카드에서 복사해 가져오기 |
| ⌘A | 보이는 사진 전체 선택 |
| ⌘클릭 / ⇧클릭 | 개별 선택 추가·해제 / 범위 선택 |
| ← / → | 이전 / 다음 사진 |
| ↑ / ↓ | 그리드에서 위 / 아래 줄 |
| 0–5 | 별점 설정 |
| P / X / U | 선택 / 제외 / 표시 해제 |
| G / E / C | 그리드 / 사진 / 비교 |
| `\` | 원본 보기 전환 |
| J | 하이라이트·섀도 잘림 표시 |
| Z | 100% 보기 전환 (가운데 기준) |
| F / Esc | 사진만 크게 보기(패널을 숨기고 전체 화면) / 끝내기 |
| ⌘Z / ⇧⌘Z | 실행 취소 / 다시 실행 (보정·별점·표시) |
| ⇧⌘E | JPEG 내보내기 |
| ⌘' | 가상 사본 만들기 |
| Delete | 카탈로그에서 빼기(확인 후, 원본 파일은 그대로) · 내 폴더에서는 그 폴더에서만 빼기 |

## 사진과 보정값 저장

원본은 가져온 위치에 그대로 유지하고, 분류와 보정값은 `~/Library/Application Support/Lighthouse/catalog.json`에 자동 저장합니다. 원본을 이동하거나 외장 드라이브 연결을 해제하면 그 사진에 **원본 없음** 표시가 붙고 왼쪽에 **원본 없음** 목록이 생깁니다. 앱으로 돌아오거나 드라이브를 연결·해제할 때마다 다시 확인합니다. 파일을 옮겼다면 오른쪽 패널이나 **사진 → 위치 다시 찾기…**에서 파일이 지금 든 폴더(또는 그 상위 폴더)를 고르세요. 같은 옛 폴더 아래에서 없어진 다른 사진도 새 위치에 파일이 있으면 함께 다시 연결합니다. 원본 삭제와 이동은 앱에서 수행하지 않습니다.

사진과 보정은 `catalog.json`, 내 폴더 구성은 같은 위치의 `folders.json`, LUT와 표시 이름은 `LUTs` 폴더, 자동 선택 마스크는 `Masks` 폴더, 보정 프리셋은 `presets.json`에 보관합니다. `Thumbnails` 폴더는 보정한 사진의 썸네일 캐시이며 지워도 다시 만들어집니다. 첫 버전은 개인 라이브러리를 대상으로 하며 수만 장의 대규모 처리 성능은 아직 검증하지 않았습니다. 백업할 때 이 파일·폴더들과 원본 사진을 함께 보관하세요. 앱은 하루에 한 번(그날 처음 열 때, 켜 둔 채 날짜가 바뀌면 그날 첫 저장 때) `Backups/YYYY-MM-DD` 폴더에 카탈로그·내 폴더·프리셋을 남기고 최근 7일치만 유지합니다. 자동 마스크는 이 보관본의 `catalog.json` 안에 들어 있어 그 폴더만으로 되돌릴 수 있습니다. **파일 › 카탈로그 보관본 보기**로 폴더를 엽니다. 되돌리려면 앱을 끝낸 뒤 원하는 날짜 폴더의 파일을 위 위치에 덮어 두세요. LUT와 원본 사진은 보관본에 들어가지 않습니다.

RAW 지원은 macOS의 카메라 지원에 따릅니다. 현재 개발 Mac에서 S9의 일반 24MP RW2를 실제 현상·내보내기로 확인했습니다. 모든 펌웨어·촬영 모드의 RW2를 확인한 것은 아닙니다. 내보내기는 SDR sRGB JPEG이며 클라우드 동기화와 Lightroom 카탈로그 호환은 제공하지 않습니다. 자동 선택은 사진에 따라 실패하거나 수동 수정이 필요할 수 있습니다.

## 검증과 개발 자료

```sh
swift test
swift build
```

테스트용 카탈로그를 분리하려면 다음과 같이 실행합니다.

```sh
LIGHTHOUSE_DATA_DIR="$PWD/.artifacts/test-catalog" swift run Lighthouse
```
