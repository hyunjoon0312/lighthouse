SFace Core ML model attribution and provenance
================================================

This resource is the OpenCV Zoo SFace face-recognition model converted from
ONNX to Core ML for use by Lighthouse. It produces an unnormalized
128-dimensional identity embedding from an aligned RGB face crop.

Modification
------------

Converted from the pinned ONNX graph to a Float32 Core ML neural-network model
by Lighthouse. The conversion maps the inference graph directly and does not
add embedding normalization. No training data or input photographs are part of
this resource or conversion process.
