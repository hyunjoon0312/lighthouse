# 사람별 사진 찾기 계약

얼굴을 분석해 이름 붙인 사람의 사진을 찾고, 같은 사람 후보를 확인해 분류한다. 얼굴 분석과 비교는 Mac 안에서 실행하며 원본·보정값·XMP는 변경하지 않는다. 외부로 사진·얼굴 특징·이름을 보내지 않고, 계정이나 런타임 모델 다운로드를 요구하지 않는다.

## 얼굴과 사람

Vision으로 보정 전 원본 미리보기의 얼굴·눈·코·입 위치를 찾는다. EXIF 방향을 반영한 영상에서 다섯 점을 맞춘 112×112 얼굴을 만든 뒤, 앱에 포함된 SFace 모델로 128차원 특징을 계산한다. 이는 얼굴 위치 검출과 구분되는 동일 인물 비교 단계다. 얼굴 ID는 사진 속 얼굴 한 개를 가리키고 사람 ID는 사용자가 이름 붙인 분류를 가리킨다. 여러 사람이 찍힌 사진은 여러 사람 목록에 들어갈 수 있다.

모델은 [OpenCV Zoo SFace](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface)에서 가져온 Apache 2.0 모델을 Core ML 형식으로 변환한다. 원본 해시, 고정 리비전, 변환 방식과 라이선스는 함께 보관한다. 변환 출력은 ONNX 원본 출력과 비교한다. 앱에서 실행할 때 Python·ONNX Runtime·OpenCV 설치는 필요하지 않다.

사용자가 확인한 얼굴만 이름 검색·사람 필터에 포함한다. 후보는 해당 사람으로 확인한 얼굴과 직접 비교하며 후보를 다시 기준으로 쓰지 않는다. 기본 후보 기준은 정규화한 특징의 코사인 유사도 0.50 이상이다. 이 값은 확률이나 정확도 퍼센트가 아니다. 같은 사진에서 이미 확인한 사람과 다른 얼굴, 다른 사람으로 분류한 얼굴, 사용자가 해당 사람 후보에서 제외한 얼굴은 추천하지 않는다. 서로 다른 자세·조명·표정, 작거나 가려진 얼굴에서는 놓치거나 잘못 추천할 수 있으므로 사용자가 확정한다.

## 화면과 조작

사이드바의 ‘얼굴 찾기 · 관리…’에서 전체 또는 선택한 사진을 분석한다. 얼굴에 이름을 붙이거나 기존 사람에 배정하고, ‘같은 사람 후보’에서 맞는 얼굴을 확인한다. 분류 해제·다른 사람으로 옮기기·이름 변경·사람 삭제·전체 얼굴 분석 정보 지우기를 제공한다. 사람을 삭제해도 사진은 남는다. 사람별 사진 목록은 기존 그리드·보정·일괄 내보내기에 연결되고, 검색창은 확인된 사람 이름도 찾는다.

## 저장과 비동기 경계

기존 사진 카탈로그와 별도인 `people.json`에 형식 버전, 모델 버전, 사람 이름, 사진별 얼굴 좌표·특징·작은 얼굴 미리보기, 확인·제외 결과를 저장한다. 원본은 읽기만 한다. 새 파일이 없으면 빈 상태로 시작하지만 손상·미지원 버전·읽기 실패는 빈 성공으로 바꾸지 않는다. 이 경우 사람 기능의 쓰기만 막고 기존 사진 보정은 유지한다. 저장 전 참조·중복 ID·숫자·이름을 검사하고 원자적으로 교체한다.

분석 대상은 시작 시점의 사진 ID와 경로로 고정한다. 파일 크기·수정 시각이 분석 전후 같고 현재 카탈로그에도 동일 사진·경로가 남아 있을 때만 결과를 적용한다. 읽기·추론 실패를 얼굴 없음으로 저장하지 않는다. 작업 취소는 다음 사진으로 진행하지 않고 완료된 결과는 남긴다. 종료는 현재 작업의 결과 반영과 저장을 기다리며 저장 실패 시 종료하지 않는다. 늦게 끝난 작업이 취소·전체 정보 삭제 이후 상태를 되살리지 못하게 한다.

명시적인 원본 위치 재연결은 기존 보정처럼 확인한 사람 분류도 같은 사진 ID에 유지한다. 그 외 원본 교체로 크기·수정 시각이 바뀌면 다음 분석 때 얼굴을 다시 계산하고 새로 확인받는다. 카탈로그에서 뺀 사진은 사람 목록과 추천에서 제외하고, 같은 실행에서 되돌렸을 때 기존 분류를 복구할 수 있다.

## 검증

- 누락·손상·버전 오류·잘못된 특징·원자 저장 실패와 기존 파일 보존.
- 이름·확인·제외·다인 사진·이름 검색·필터·재시작·원본 재연결.
- 정규화·RGB 순서·상하 방향·좌표 변환과 원본 모델 대비 수치 비교.
- 서로 다른 사진의 동일 인물 표본, 다른 사람 표본, 다인 사진, 회전 EXIF, 얼굴 없는 사진과 읽기 실패.
- 취소·삭제·선택 변경·늦은 결과·저장 실패·종료 대기와 원본 SHA-256 보존.
- 실제 화면과 배포 앱에서 모델 자원을 읽고 실행하는지 확인. 표본 검사와 전체 인식 정확도 보장을 구분한다.
