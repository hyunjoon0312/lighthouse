# 여러 사진 편집하기

그리드나 (사진·비교 보기의) 아래 필름스트립의 체크 버튼으로 여러 장을 선택합니다. ⌘클릭은 한 장씩 추가·해제하고, ⇧클릭은 범위를 선택합니다. ⌘A 또는 **전체 선택**은 현재 필터에 보이는 사진을 모두 선택합니다.

선택한 사진 중 **기준** 표시가 있는 사진을 오른쪽 슬라이더로 보정합니다. 선택한 사진을 더블클릭하면 선택 그룹을 유지하면서 기준 사진으로 볼 수 있습니다. 슬라이더는 기준 사진에만 적용됩니다.

**일괄 적용…**을 열면 기준 사진과 대상 파일 목록을 확인할 수 있습니다. 복사할 항목을 선택해 적용하세요.

- 전체 보정: 노출, 대비, 색온도, 틴트, 하이라이트, 섀도, 명료도, 생동감, 채도, 선명도, 비네팅, RGB 곡선, 색상 범위(HSL), 필름 입자, 일반·AI 노이즈 감소, RAW 현상(노이즈 감소·렌즈 보정·하이라이트 복구).
- LUT: 파일 선택, 강도, 활성화. 기준 사진의 LUT가 없으면 대상의 LUT도 해제됩니다.
- 회전·크롭: 회전과 중앙 비율 크롭.
- 부분 보정 영역: 모든 영역을 같은 상대 위치로 복사합니다. 사진의 피사체 위치가 다르면 다시 조절해야 합니다.

보정 **복사**(⇧⌘C) 후 **다음에 붙여넣기**는 다음 사진에, **보정 붙여넣기**(⇧⌘V)는 선택한 모든 사진(선택이 없으면 보고 있는 사진)에 전체 보정(빛·색·명료도·생동감·비네팅·곡선·HSL·선명도·입자·노이즈 감소·RAW 현상)과 LUT만 옮깁니다. ⇧⌘V는 여러 장이어도 ⌘Z 한 번으로 되돌아갑니다. 크롭·부분 보정·복구는 사진마다 위치가 달라 제외하므로, 이것까지 옮기려면 일괄 적용에서 항목을 고르세요. 슬라이더를 한 번 드래그한 변경은 ⌘Z 한 번으로 되돌아갑니다.

자주 쓰는 조합은 **프리셋**으로 저장해 두면 여러 장을 선택한 뒤 프리셋 이름을 눌러 한 번에 적용할 수 있습니다. 이것도 ⌘Z 한 번으로 되돌아갑니다.

LUT만 빠르게 복사하려면 오른쪽 **선택한 N장에 LUT 적용**을 사용하세요. 어떤 방식을 쓰든 ⌘Z 한 번으로 해당 일괄 적용 전체를 되돌릴 수 있습니다. 각 사진의 서로 다른 원래 보정값으로 복원됩니다. 실행 취소 기록은 앱 실행 중에 유지됩니다.

검색이나 폴더 필터를 바꾸면 화면에서 숨겨진 사진은 선택에서 제외됩니다. 일괄 적용은 현재 보이는 선택 사진에만 수행합니다. 별점·분류·원본 파일은 보정 복사로 바뀌지 않습니다.

**내보내기 → 선택한 사진**으로 선택한 장수만 내보낼 수 있습니다. 두 장 이상 선택하면 이 옵션이 기본값입니다. 파일은 별도로 저장되고 기존 파일명이 있으면 새 이름을 붙입니다.
