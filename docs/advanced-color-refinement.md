# 고급 색 처리 보완 v1.1

`advanced-editing-contract.md`의 공개 모델·API·처리 순서는 유지한다. 아래 수치 처리 두 항목은 색상 범위와 입자 구현에서 우선 적용한다.

1. **무채색 보호:** 특정 색상 범위가 회색을 빨갛게 물들이지 않도록 모든 HSL 변화의 가중치에 `min(1, originalSaturation / 0.15)`를 곱한다. hue에는 기존 원래 saturation 감쇠도 유지한다. hue=0으로 표현된 회색은 빨강 범위에 속한 것으로 처리하지 않는다. 정확한 회색은 모든 범위 조절에서 동일해야 하며 낮은 채도에서 연속적으로 영향이 커져야 한다.
2. **입자 seed 정밀도:** 저장된 UInt32를 그대로 Float로 바꿔 큰 위상으로 더하면 이웃 픽셀의 좌표 차이가 사라질 수 있다. 커널의 seed 위상은 `Double(seed & 0xffff) * 0.001 + Double(seed >> 16) * 0.173`으로 만든 뒤 Float로 전달한다. 원본 seed는 그대로 저장한다. 최대 seed 부근에서도 화면 전체가 상수 또는 큰 띠가 되지 않고, 같은 seed는 같은 무늬를 재현해야 한다.

검사는 무채색의 색상 범위 불변성과 큰 seed(예: UInt32.max)의 입자 분산·재현성을 포함한다. 0…1 수치 범위, alpha와 neutral 우회는 원래 계약을 따른다.
