# Lightroom식 선별 흐름 보완

2026-10-07 사용자는 프리셋·색감과 라이브러리·선별을 우선했다. 기존 P/X/U·별점·자동 다음 사진·비교·여러 장 보기·스마트 폴더를 활용하면서 접근을 줄인다.

앱 작업자는 WorkspaceView의 도구 줄 아래에 얇은 빠른 선별 줄을 둔다. `전체 표시`, `채택`, `미분류`, `제외` 네 단추는 기존 `criteria.flag`의 nil/pick/none/reject와 연결한다. `전체 표시`는 표시 조건만 지우고 폴더·검색·별점·나머지 조건은 유지한다. 새 저장 필드나 새 필터 enum은 만들지 않는다. 조건 팝오버와 양방향으로 같은 상태를 보여 준다. `미분류`는 PhotoFlag.none이며 별점의 유무와는 별개다. 단추별 도움말과 선택 접근성 상태를 제공한다.

같은 줄 오른쪽 `프리셋 적용` 메뉴는 저장한 모든 프리셋과 Lightroom 프리셋 가져오기 액션을 제공한다. 선택 수를 도움말/레이블에 표시하고 사진 선택이 없으면 적용 항목만 비활성화한다. 파일 가져오기는 선택이 없어도 가능하다. 가져온 프리셋의 호환 정보는 기존 프리셋 관리/결과 시트에서 확인한다. 기존 `model.applyPreset`을 공통 사용하여 여러 장 적용·개별 속성 보존·한 단계 실행 취소를 유지한다.

좁은 창에서 네 표시 단추는 Picker/Menu로 접어 기존 최소 창 크기에 맞춘다. 외형은 기존 중성 회색·주황 강조색과 맞춘다. 라이브러리가 비어도 가져오기 메뉴는 살아 있다.

검증: 전체/채택/미분류/제외 전환, 기존 검색·별점·폴더와 조합, 미분류에서 P/X 후 자동 다음 사진이 건너뛰지 않음, 다중 선택 프리셋 적용 및 undo, 필터로 가려진 사진 제외. UI는 넓은 창과 최소 폭에서 확인한다. 기존 SelectionMarkTests/WorkflowAppTests와 신규 LightroomPresetFlowTests를 사용한다.

소유: app Sol의 WorkspaceView.swift 및 LibraryModel 소유권에 포함한다. 별도 상태 파일이나 역할 추가는 없다. 메인은 사용 안내·검증 기록을 담당한다.

## 가져오기 비동기 경계 추가 결정

- `isPresetImporting`, task/generation 상태는 LibraryModel.swift에만 둔다. 최대 2 MiB/파일 코어 제한을 사용하며 파싱을 메인 액터 밖에서 한다. 다중 파일 결과는 메인으로 한 번 돌려준다.
- 시작은 catalogLoaded 및 presetLoadError 없음, 진행 중 중복 요청 없음이 조건이다. 완료 시 최신 `presets`에 합쳐 이름 충돌을 해소하고 저장한다. 초기 목록 스냅숏으로 덮어쓰지 않는다. 저장 실패면 추가된 것으로 보고하지 않고 기존 메모리·디스크를 보존한다.
- `LibraryModel+Workflows.swift`의 `hasConflictingWorkflow`에 프리셋 가져오기 상태를 추가하여 라이브러리 전환을 막는다. LibrarySession.swift는 기존 사용자 변경이 있어 수정하지 않는다.
- `cancelPresetImport()`는 generation을 무효화하고 작업을 취소하며 읽기 결과를 폐기한다. 가져오기 중 앱 종료 경로의 확인·취소에 이 작업도 연결한다. 파싱은 읽기 전용이고 취소 이후 저장하지 않으므로 별도 파일 쓰기 drain은 필요하지 않다. 상태를 false로 돌려도 이전 작업의 늦은 완료가 새 작업 상태를 해제하지 않게 한다.
- `hasModalPresentation`에 결과/호환 시트를 추가하고 검색 입력 중 P/X 등 사진 단축키가 발동하지 않는지 기존 입력 보호를 확인한다.
- 적용은 현재 visible ID와 선택 ID의 교집합만 대상으로 하며 preset.applied를 사진별로 호출한다. 사진 선택 변경은 가져오기 결과에 영향을 주지 않고 가져온 것을 임의로 현재 사진에 적용하지 않는다.
- 기존 프리셋은 lightroom이 nil이면 기존 동작을 그대로 유지한다. `writePresets` 재사용을 위해 같은 extension 파일에 구현하거나 private를 필요한 내부 접근으로만 바꿀 수 있다.
- 새 테스트에는 필터 조합·저장 재로드·일괄 undo/redo 외에 가져오기 중 중복/취소·라이브러리 전환 차단·메모리 최신 목록 병합·지원 프리셋의 실제 생성 이미지 preview/JPEG 출력 차이 및 원본 SHA 보존을 포함한다. 실제 S9 검사는 메인이 별도로 담당한다.
