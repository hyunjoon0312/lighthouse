# 고급 보정 사용 안내

모든 기능은 원본을 보존하고 보정값을 카탈로그에 저장합니다. 실행 취소·다시 실행과 앱 재시작 후 보정 복원을 지원합니다.

## 피사체와 배경 선택

부분 보정에서 **피사체 선택** 또는 **배경 선택**을 누르면 macOS Vision이 사진 안의 두드러진 피사체를 찾습니다. 배경 선택은 같은 마스크를 반전합니다. 처리는 Mac 안에서 이루어집니다.

생성된 영역에서 노출·대비를 조절하세요. 브러시로 영역을 더하거나 지우개로 덜어낼 수 있고, 경계 부드럽게로 가장자리를 조절합니다. 사람뿐 아니라 동물·물체가 선택될 수 있습니다. 피사체가 불분명한 풍경이나 복잡한 경계는 자동 선택이 실패하거나 수정이 필요할 수 있습니다. 이때 기존 영역 추가와 브러시를 사용하세요.

마스크는 생성 결과 자체를 저장합니다. 다시 열 때 재인식하지 않으며, 처리 중 다른 사진이나 보정 상태로 바뀌면 오래된 결과를 적용하지 않습니다.

## 곡선과 색상 범위

전체 보정의 곡선에서 RGB 전체 또는 R/G/B 채널을 선택합니다. 그래프를 클릭해 점을 추가하고 드래그해 입력 밝기와 출력 밝기의 관계를 바꿉니다. 내부 점은 삭제할 수 있고 채널별로 초기화합니다.

색상 범위에서는 빨강·주황·노랑·초록·아쿠아·파랑·보라·마젠타 중 하나를 고르고 색조·채도·명도를 조절합니다. 예를 들어 주황의 채도·명도로 피부색을, 파랑의 색조·채도로 하늘을 조절할 수 있습니다. 가까운 색상에도 부드럽게 영향을 줍니다.

곡선과 색상 범위는 SDR sRGB 수치에서 처리되고 기존 LUT보다 먼저 적용됩니다. RAW 현상 과정 전체를 8비트로 변환하지 않습니다.

## 자유 크롭과 수평

자유 크롭에서 사각형 안을 드래그하면 위치를, 모서리를 드래그하면 크기를 바꿉니다. 자유 비율과 고정 비율을 선택할 수 있습니다. 수평 슬라이더는 -20°부터 +20°까지 조절합니다.

수평을 돌릴 때 생기는 빈 모서리는 자동으로 잘라냅니다. 적용 전 시트에서 결과를 확인하고, **적용**하면 한 번의 실행 취소로 복원할 수 있습니다. **취소**하면 기존 구도를 유지합니다. 90° 회전과 함께 사용할 수 있으며 회전 방향을 바꾸면 자유 크롭 프레임은 초기화됩니다.

## 스팟 복구와 복제

복구 패널에서 작은 먼지나 잡티는 **스팟 복구**로 클릭하거나 짧게 칠합니다. 주변의 비슷한 패치를 찾아 질감을 가져오고 밝기 차이를 완화합니다. 큰 물체를 새 배경으로 생성하는 기능은 아닙니다. 자연스러운 주변 패치를 찾기 어려우면 브러시를 줄이거나 복제를 사용하세요.

**복제**는 소스를 직접 고릅니다. 소스 선택 버튼을 누르고 깨끗한 위치를 클릭한 뒤 목적 영역을 칠하세요. 각 작업은 목록에서 켜고 끄거나 삭제할 수 있습니다. 드래그 한 번은 실행 취소 한 번에 해당합니다.

마스크와 복구 위치는 원본 좌표로 저장되어 이후 크롭·수평·회전을 바꿔도 같은 위치를 따라갑니다. 그리기는 화면 맞춤의 보정 보기에서 사용합니다.

## 필름 입자

전체 보정에서 입자의 양과 크기를 조절합니다. 크기는 원본 픽셀을 기준으로 하며, 같은 설정은 미리보기와 JPEG에 같은 무늬로 적용됩니다. 패턴 새로 만들기로 다른 무늬를 선택할 수 있습니다. 양을 0으로 하면 입자를 적용하지 않습니다.

## JPEG 압축 미리보기

내보내기에서 긴 변과 품질을 바꾸면 실제 JPEG로 압축한 사진, 픽셀 치수와 파일 크기가 갱신됩니다. 100% 보기에서 압축 흔적을 확인할 수 있습니다. 준비가 끝나야 내보내기 버튼이 활성화됩니다.

한 장의 미리보기 데이터는 그대로 파일에 저장합니다. 여러 장을 내보낼 때 표시되는 크기는 대표 사진 한 장의 크기이며 합계 예상치가 아닙니다. 다른 사진도 같은 출력 옵션으로 처리합니다. 파일명이 겹치면 접미사를 붙이고 기존 파일을 보존합니다.

## 일괄 적용과 LUT의 범위

전체 보정 복사에는 곡선·색상 범위·입자가 포함됩니다. 구도 복사에는 자유 크롭과 수평이 포함되며, 부분 보정과 복구는 각각 선택해서 복사합니다. 마스크와 복구는 같은 정규화 위치를 복사하므로 다른 구도의 사진에서는 위치를 확인해야 합니다. 대상 사진마다 자동으로 피사체를 다시 찾지는 않습니다.

참조 사진을 이용한 LUT 생성은 색 변환을 저장합니다. 부분 마스크, 크롭, 복구 위치와 필름 입자는 일반적인 3D LUT로 표현할 수 없으므로 LUT 파일에 담기지 않습니다. S9 전달 방법과 실기 검증 범위는 [참조 색감과 S9 안내](reference-match.md)를 참고하세요.
