# 노이즈 감소

사진 편집의 **전체 보정 → 노이즈 감소**에서 방식을 고릅니다. JPEG·HEIC·PNG·TIFF와 macOS에서 현상할 수 있는 RAW에 사용할 수 있습니다.

- **끔**: 추가 노이즈 감소를 적용하지 않습니다.
- **일반**: 빠른 노이즈 감소입니다. **강도**를 높이면 작은 밝기 변화가 더 부드러워집니다.
- **AI**: 앱에 포함한 FFDNet 학습 모델로 노이즈를 줄입니다. Mac 안에서 처리하므로 인터넷·계정·별도 모델 설치가 필요 없습니다.

처음에는 낮은 강도부터 올리며 **100% 확대**해서 피부·머리카락·글자·잔무늬를 확인하세요. 강도가 너무 높으면 디테일도 부드러워질 수 있습니다. 0%에서는 사진을 그대로 통과시키며, **초기화**로 이 항목만 기본값으로 되돌릴 수 있습니다. 기존 **선명도**는 별도로 조절합니다.

AI는 원본 해상도를 처리하므로 큰 사진의 첫 결과에는 시간이 걸립니다. 처리 중에는 기존 렌더 진행 표시가 나타납니다. 최근에 처리한 같은 원본·입력 보정·노이즈 설정의 결과는 재사용합니다. 여러 영역이나 전체·부분 AI를 함께 사용하면 캐시 교체로 다시 처리할 수 있습니다. RAW 노출·색온도·RAW 현상 옵션, 플리커 보정이나 노이즈 강도가 바뀌면 다시 처리합니다. 현재 AI 처리 한도는 6,400만 화소입니다.

## 부분 영역에 적용하기

**부분 보정**에서 피사체·배경·밝기 범위·색상 범위·브러시·그라데이션 영역을 만들고 그 영역의 **노이즈 감소**를 조절합니다. 전체 노이즈 감소 결과를 공통 입력으로 처리하며, 겹치는 곳은 뒤쪽 영역의 결과가 우선합니다. 저장한 마스크·일괄 복사·실행 취소·내보내기에 함께 반영됩니다. [범위 마스크와 부분 노이즈 감소](photo-workflow.md#밝기색으로-부분-영역-선택)를 참고하세요.

원본이 없는 스마트 미리보기 모드에서는 노이즈 감소 결과를 표시하지 않습니다. 설정값은 유지하고 원본을 다시 연결하면 적용합니다.

## 여러 장에 적용하기

현재 사진의 노이즈 감소를 설정한 뒤 사진들을 선택하고 **일괄 적용… → 전체 보정**을 포함해 적용합니다. **보정 복사·붙여넣기**, 프리셋, 스냅샷에도 설정이 함께 들어갑니다. ⌘Z로 되돌릴 수 있습니다. 결과를 JPEG·HEIF·TIFF 등으로 내보내면 노이즈 감소가 포함되며 원본 파일은 바뀌지 않습니다.

## RAW 현상 항목과의 차이

기존 **RAW 현상 → 노이즈 감소 / 색 노이즈 감소**는 macOS RAW 디코더의 기능입니다. 새 **노이즈 감소 → AI**는 디코더로 현상한 RGB 이미지에 적용됩니다. 두 기능을 함께 쓸 수 있지만, 강도를 모두 높이면 질감이 과하게 줄어들 수 있습니다.

AI는 SDR 색상 이미지의 노이즈를 줄이도록 학습한 모델입니다. 카메라 센서 데이터를 직접 복원하는 AI RAW 현상이나 생성형 디테일 복원 기능은 아닙니다. 실촬영 노이즈·JPEG 압축 흔적·HDR 사진에서의 효과는 사진에 따라 다릅니다. 전·후 보기로 결과를 확인하세요.

모델·색 처리·저장 계약은 [구현 계약](denoise-contract.md), 실제 검사는 [검증 기록](verification.md)을 참고하세요.
