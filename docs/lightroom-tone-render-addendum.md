# 추가 톤 렌더 보완 v2

2026-10-07, 메인 Astra의 경계 분석에 따른 [v1 계약](lightroom-tone-contract.md) 보완. 아래 한 항목만 v1보다 우선한다. 모델·파서·앱 API 및 나머지 계약은 같다.

v1의 ‘0…1 밖 채널을 그대로 보존’은 흰색/검정의 끝점이 이동할 때 경계에서 톤이 불연속이 된다. 예를 들어 흰색 -100에서 x=1은 0.75, x=1.001은 1.001이 된다. 포화 채널과 확장 범위에 줄무늬/색 경계를 만들 수 있으므로 이 규칙을 수정한다.

추가 톤 커널은 unpremultiplied 채널 `original`에 대해 `base=clamp(original,0,1)`로 v1의 순차 곡선을 계산한다. 결과 `curved`를 0…1로 clamp한 뒤 `changed = original + (curved-base)`를 출력한다. 따라서 범위 밖에서는 가장 가까운 끝점의 이동량을 더하며 확장 범위의 상대 차이를 보존한다. 투명도는 그대로 유지하고 다시 premultiply한다. 모든 새 제어가 0이면 기존처럼 완전 no-op이다.

검증에는 -0.001/0/0.001 및 0.999/1/1.001 경계의 연속성, HDR 범위가 전부 1로 잘리지 않음, 유한 결과, alpha 보존을 포함한다. 내부 채널 색감·단조성 검사는 v1 그대로다.
