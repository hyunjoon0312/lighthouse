# 참조 사진 색감과 S9용 LUT

**참조 사진 색감 맞추기…**는 원하는 사진의 밝기·대비·색 분포를 현재 사진에 근사합니다. 모든 분석은 Mac 안에서 수행하고 사진을 외부로 보내지 않습니다.

## 만들기

1. 보정할 사진을 선택하고 **전체 보정 → 참조 사진 색감 맞추기…**를 엽니다.
2. **참조 사진 선택…**으로 원하는 분위기의 JPEG·PNG·HEIC·TIFF·지원 RAW를 선택합니다. 참조 사진은 라이브러리에 자동 등록되지 않습니다.
3. 현재 사진, 참조 사진, 색감 맞춘 결과를 비교하고 강도를 조절합니다.
4. LUT 이름을 정하고 **보관하고 현재 사진에 적용** 또는 **LUT만 보관**을 선택합니다. 이후 보관한 LUT 목록에서 다시 사용할 수 있습니다.

분석은 현재 사진의 기존 LUT를 제외한 상태를 기준으로 합니다. 적용하면 현재 LUT가 새 결과로 대체되고 다른 보정은 유지됩니다. LUT만 보관하거나 시트를 닫으면 사진의 보정은 바뀌지 않습니다. 여러 사진에 같은 결과를 쓰려면 보관한 LUT를 고른 뒤 **선택한 N장에 LUT 적용**을 누르세요.

이 기능은 피사체를 인식해서 같은 부위끼리 맞추거나 원본 프리셋을 추출하는 기능은 아닙니다. 사진 구도·피사체·조명이 비슷할수록 결과를 비교하기 쉽습니다. LUT에는 생성한 색 변환과 선택한 강도만 담기며, 브러시 영역·크롭·선명도나 기존 보정 설정은 포함되지 않습니다. 적용 후 보정 패널에서 추가로 조절할 수 있습니다.

## S9에 넣기

S9는 외부 `.cube` LUT를 지원합니다. **S9용 .cube 내보내기…**는 33격자, full range, Standard 기반 태그를 포함한 UTF-8 파일을 만듭니다. 앱의 색 변환은 sRGB 사진용이므로 V-Log 기반으로 사용하면 안 됩니다. [S9 공식 LUT Library 안내](https://eww.pavc.panasonic.co.jp/dscoi/DC-S9/html/DC-S9_DVQP3138_eng/0074.html)

파일명은 기본 `LHLOOK01.cube`이며 영문자·숫자 1–8자로 정합니다. 다음 중 하나로 옮길 수 있습니다.

- **SD 카드:** 파일을 카드의 최상위 폴더에 복사합니다. S9에 카드를 넣고 **LUT Library → 등록할 슬롯 → Load**에서 파일을 선택한 뒤 Real Time LUT에서 사용합니다.
- **LUMIX Lab:** 파일을 스마트폰에 옮긴 뒤 **LUT 라이브러리 → 장치 → 추가**에서 가져옵니다. S9와 연결하고 **카메라로 전송**합니다. LUMIX Lab은 33격자 `.cube` 가져오기를 지원합니다. [LUMIX Lab 한국어 안내](https://av.jpn.support.panasonic.com/support/global/cs/soft/lumix_lab/ko/cts/d0.html)

생성 파일의 `TITLE` 바로 아래에는 `#LUMIXPHOTOSTYLE STD`가 들어갑니다. 이 정보를 제거하면 S9가 V-Log 기반으로 해석할 수 있으므로 유지하세요. 처음 사용할 때 카메라 화면의 기반 Photo Style이 Standard인지 확인하세요.

**공식 지원 규격 확인과 실제 카메라 검증은 다릅니다.** 이 개발 환경에는 연결된 S9가 없어 파일을 기기에 넣어 촬영하는 검증은 하지 않았습니다. macOS RAW 현상과 S9의 Standard 처리, 노출·화이트밸런스가 달라 앱 미리보기와 동일한 색감을 보장하지 않습니다. 앱에서 만든 파일을 옮긴 뒤 같은 장면에서 비교 촬영하고 강도를 조절하세요. 임의로 가져온 65격자/V-Log LUT까지 S9 호환으로 바꾸는 기능은 제공하지 않습니다.
