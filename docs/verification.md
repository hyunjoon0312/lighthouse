테스트 카탈로그는 `.artifacts/lut-validation/ui-catalog`, 독립 검사 코드·이미지는 `.artifacts/lut-validation`에 격리했다. 테스트 사진·LUT는 기본 사용자 카탈로그와 배포 번들에 포함하지 않는다. V-Log 입력 변환, .vlt, 1D/shaper, 카메라 내 LUT와의 색상 일치, 사용자가 보유한 모든 제작사 LUT는 미지원 또는 미검증 범위다.

이번 확장 UI의 실제 클릭 검증은 **미완료**다. release 실행 프로세스는 정상 이벤트 루프에 진입했지만 CUA 도구가 반복해서 `cgWindowNotFound`를 반환했다. 번들 경로/ID 접속, 새 도구 세션, 앱 재실행으로도 창을 읽지 못했다. 화면 잠금 여부를 사용자에게 문의했으며 이 시점에는 확인되지 않았다. 따라서 앞선 버전의 UI 검증 기록을 이번 기능의 검증으로 간주하지 않는다. 새 선택 체크·시트·파일 선택창과 레이아웃은 화면 접근이 복구되면 추가 확인해야 한다.

S9에서의 외부 LUT 사용 가능 여부는 [공식 매뉴얼](https://eww.pavc.panasonic.co.jp/dscoi/DC-S9/html/DC-S9_DVQP3138_eng/0074.html)과 [LUMIX Lab 안내](https://av.jpn.support.panasonic.com/support/global/cs/soft/lumix_lab/ko/cts/d0.html)로 확인했다. 카메라가 연결되어 있지 않아 실기 로딩·촬영 결과는 미검증이며, 앱의 RAW 현상과 카메라 Standard 처리 간 색 일치도 보장하지 않는다.
