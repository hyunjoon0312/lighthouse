# 연속 촬영 고르기

왼쪽 **연속 촬영**을 누르면 같은 카메라로 1초 이내에 이어 찍은 컷만 모아 보여 줍니다. 타일의 **연속 2/5**는 다섯 컷 중 두 번째라는 뜻입니다. 촬영 시각이 없는 사진은 묶지 않습니다. 같은 폴더에 이름이 같은 RAW+JPEG는 한 컷으로 봅니다.

## 베스트 컷 추천

1. **베스트 컷 분석**을 누르면 지금 목록에 보이는 묶음을 분석합니다. 검색이나 별점 필터로 범위를 좁힐 수 있습니다.
2. 끝나면 묶음마다 한 컷에 **추천** 표시가 붙습니다.
3. **추천 컷 선택**은 추천 컷만 선택해 비교하거나 일괄 적용할 수 있게 합니다. **추천 P · 나머지 X 표시**는 추천 컷을 선택(P), 나머지를 제외(X)로 표시합니다. 이미 별도로 표시한 사진은 바꾸지 않으며 ⌘Z 한 번으로 되돌립니다.

분석을 **중지**하면 이미 분석한 컷은 기억하지만, 모든 컷을 보지 못한 묶음은 추천하지 않고 표시도 바꾸지 않습니다. **베스트 컷 분석**을 다시 누르면 남은 컷만 분석합니다. 읽지 못한 파일은 추천에서 빼고 선택·제외 표시를 붙이지 않습니다.

분석은 Mac 안에서만 합니다. 원본 미리보기(RAW는 파일에 든 카메라 미리보기)를 긴 변 1024px로 읽어 다음을 비교합니다.

- **선명도**: 사진에서 가장 선명한 10% 부분의 세부 대비. 배경이 흐린 사진도 초점 맞은 피사체로 판단합니다.
- **얼굴 촬영 품질**: 얼굴이 찍힌 컷이 있으면 macOS Vision의 얼굴 품질(눈 감음·흔들림·각도 등)을 절반 반영합니다. 얼굴이 없는 풍경·사물은 선명도만 봅니다.
- **눈 감은 컷**: macOS Core Image 얼굴 검출기로 두 눈을 감은(또는 가려진) 얼굴을 찾아 타일에 **눈 감음**을 붙입니다. 눈을 뜬 컷이 하나라도 있으면 눈 감은 컷은 점수가 높아도 추천하지 않고, 모두 눈을 감았으면 점수로 고릅니다. 여러 사람 중 한 사람만 감아도 눈 감은 컷입니다.

결과는 보정 전 원본 기준이며 이번 실행 동안만 기억합니다. 앱을 다시 열면 다시 분석하세요. 추천은 참고용입니다. 표정·구도·순간의 좋고 나쁨은 판단하지 않으므로 마지막 선택은 직접 확인하세요.

## 확인한 범위

CC0 인물 사진 한 장으로 만든 4컷(원본, 가우시안 흐림, 움직임 흐림, 눈 부분을 가린 컷)에서 원본을 추천했습니다. 점수는 0.73, 0.27, 0.28, 0.64였습니다. 얼굴 품질은 흐림에 거의 반응하지 않고(0.46→0.48) 눈을 가리면 떨어졌습니다(0.46→0.28). 실제 S9 연사 파일과 여러 사람이 나온 단체 사진에서는 확인하지 않았습니다.

눈 감음 판단은 위키미디어 공용의 공개 사진(눈 감은 여성 분류 8장, 여성 인물 사진 10장)과 위 표본으로 확인했습니다. 눈 뜬 얼굴 13개는 모두 뜬 것으로, 감은 얼굴 7개는 모두 감은 것으로 봤고, 눈을 거의 내리감은 1개와 눈을 가린 컷은 감은 것으로 봤습니다. Vision 얼굴 특징점의 눈 높이·너비 비율은 감은 눈(0.32)과 뜬 눈(0.26)을 가르지 못해 쓰지 않았습니다. 확인에 쓴 사진은 저장소에 넣지 않았습니다.
