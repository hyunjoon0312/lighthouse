# LUT 사용 안내

LUT는 색을 다른 색으로 바꾸는 표입니다. Lighthouse에서는 사진의 전체적인 색감을 `.cube` 파일로 적용할 수 있습니다.

## 적용하기

1. 사진을 선택하고 오른쪽 **전체 보정** 패널을 엽니다.
2. 위쪽 **LUT**에서 **.cube 추가…**를 누르고 하나 이상의 LUT 파일을 선택합니다. 사진이 없을 때도 파일 메뉴에서 미리 추가할 수 있습니다.
3. **보관한 LUT** 목록에서 사용할 LUT를 고릅니다. 여러 파일을 함께 추가한 경우 현재 색감은 유지하며, 한 파일만 추가하면 현재 사진에 적용합니다. 같은 내용의 파일은 중복 항목으로 만들지 않습니다.
4. **LUT 강도**를 0–100%로 조절합니다. 0%는 LUT 효과가 없고 100%는 전체 효과입니다. 목록에서 다른 LUT를 고를 때 현재 강도를 유지합니다.
5. 활성화를 끄면 선택한 LUT와 강도를 유지하면서 효과만 끕니다. **LUT 제거** 또는 **없음**은 현재 사진의 LUT 선택을 해제하며 보관 목록에는 남습니다.

여러 사진을 선택한 상태에서 **선택한 N장에 LUT 적용**을 누르면 기준 사진의 LUT·강도·활성화를 복사합니다. 다른 보정은 각 사진의 값을 유지합니다. [일괄 편집 안내](batch-editing.md)를 참고하세요. 참조 사진에서 새 LUT를 만드는 방법과 S9 전송 방법은 [참조 색감 안내](reference-match.md)에 있습니다.

기본 노출·색상 보정과 브러시 부분 보정 뒤에 LUT가 적용됩니다. 따라서 부분 보정으로 밝힌 영역에도 최종 LUT 색감이 반영됩니다. 원본 보기에서는 모든 보정과 함께 LUT도 우회합니다.

LUT 선택·강도·활성화는 보정 실행 취소/다시 실행, 보정 복사/다음 사진에 붙여넣기, 초기화, 자동 저장에 포함됩니다. JPEG에는 화면의 보정 결과가 적용됩니다.

## 파일과 색상

- 지원 형식은 **3D `.cube`**, 크기는 2–65입니다. 일반적인 17·33·65 포인트 파일을 포함합니다. TITLE, DOMAIN_MIN/MAX 및 LUT_3D_INPUT_RANGE를 읽습니다.
- 사진용 **SDR sRGB 입력·출력** 색감을 기준으로 적용합니다. LUT 파일 자체에는 정확한 입력 색공간이 없는 경우가 많으므로 제작자가 안내한 용도를 확인하세요.
- **V-Log 전용 LUT의 입력 변환**, Panasonic `.vlt`, 1D 또는 shaper가 결합된 LUT는 지원하지 않습니다. S9의 RW2를 현상한 결과에 LUT를 적용하는 기능이며 카메라 내 Real Time LUT 결과와의 일치를 보장하지 않습니다.
- 행 수가 부족하거나 숫자가 잘못된 LUT는 적용하지 않고 오류를 표시합니다. 기존 보정은 유지됩니다.

불러온 파일은 `~/Library/Application Support/Lighthouse/LUTs/`에 복사됩니다. 파일 내용의 SHA-256을 보관 이름으로 사용하므로 같은 파일을 다시 불러와도 중복 복사하지 않습니다. 원래 `.cube` 파일을 옮겨도 앱의 보정은 유지됩니다.

백업할 때는 **catalog.json과 LUTs·Masks 폴더**, 그리고 원본 사진을 함께 보관하세요. 사진에서 LUT를 제거해도 다른 사진과 실행 취소에서 사용할 수 있도록 보관 파일은 유지합니다. 보관 파일이 사라지거나 손상되면 해당 LUT가 활성화된 사진의 미리보기·내보내기에 오류를 표시합니다. LUT를 끄거나 다시 불러와 복구할 수 있습니다.
