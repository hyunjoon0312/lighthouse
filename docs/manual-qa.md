# 화면 수동 점검표

자동 검사(`swift test`의 `LighthouseCoreTests`·`LighthouseTests`)는 코어와 `LibraryModel`의 동작을 확인하지만, 실제 화면의 모습과 클릭·키 입력은 확인하지 못한다. 2026-09-26 다시 시도했을 때도 이 개발 Mac에서는 화면 접근이 막혀 있었다(`screencapture` 결과가 검은 화면이고 Orca의 접근성 읽기가 막힘. Orca는 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 Orca Computer Use를 껐다 켜라고 안내한다). 아래 항목은 사람이 직접 확인해야 한다.

## 준비

원래 카탈로그를 건드리지 않도록 빈 폴더를 카탈로그로 쓴다. 표본 사진은 복사본을 쓴다.

```sh
./scripts/build-app.sh
mkdir -p /tmp/lh-qa/data /tmp/lh-qa/photos
cp <S9 RW2와 같은 이름의 JPG, 다른 JPEG 몇 장> /tmp/lh-qa/photos/
LIGHTHOUSE_DATA_DIR=/tmp/lh-qa/data dist/Lighthouse.app/Contents/MacOS/Lighthouse --import /tmp/lh-qa/photos
```

각 항목은 **동작 → 기대 결과**다. 다르면 무엇을 했고 무엇이 보였는지 적는다.

## 입력과 이동

- [ ] 한글 입력 상태에서 P·X·U·0–5·G·E·C·Z·J·F·`\`를 누른다 → 영문 상태와 같은 동작을 한다.
- [ ] 검색창에 한글을 입력한다 → 글자가 입력되고 단축키가 실행되지 않는다. Esc로 검색창에서 빠져나온다.
- [ ] 그리드 선택 줄의 썸네일 크기 슬라이더를 끝까지 움직인다 → 칸 크기가 바뀌고 ↑/↓가 바뀐 줄 단위로 움직인다. 앱을 다시 열어도 크기가 남는다.
- [ ] 정렬 메뉴에서 파일 이름 순·별점 높은 순·촬영 시각 순을 고른다 → 목록 순서가 바뀌고 선택한 사진은 유지된다.
- [ ] 창을 가장 작게(1100×720) 줄인다 → 위쪽에 지금 보는 목록 이름과 장수가 남고, 별점·정렬은 아이콘 메뉴로, 선택 줄의 두 확인란은 "보기" 메뉴로 접혀 모든 단추를 누를 수 있다. 창을 넓히면 원래 모양으로 돌아온다.
- [ ] 그리드에서는 아래 필름 스트립이 없고, 가져오기 진행·안내는 그리드 아래에 보인다. 사진·비교·여러 장 보기에서는 필름 스트립이 보인다.

## 단축키 안내

- [ ] ?(⇧/) 또는 도움말 › 단축키 보기(⌘/) → 단축키 창이 열리고 Esc나 닫기로 닫힌다. 한글 입력 상태에서도 ?로 열린다.
- [ ] 보기 메뉴에 그리드 (G)·사진 (E)·비교 (C)·원본 보기 (\)·100% 보기 (Z)·잘림 표시 (J)·사진만 보기 (F), 사진 메뉴에 선택 (P)·제외 (X)·해제 (U)·별점이 보이고 누르면 같은 동작을 한다.
- [ ] 검색창에 p나 ?를 입력한다 → 글자가 입력되고 표시나 단축키 창이 동작하지 않는다.

## 여러 장 보기(N)

- [ ] 그리드에서 4장을 ⌘클릭으로 고르고 N → 화면이 2×2로 나뉘어 4장이 크게 보이고, 먼저 썸네일이 보였다가 선명한 그림으로 바뀐다.
- [ ] 칸을 누르면 주황 테두리(기준)가 옮겨 가고 P·X·0–5·6–9가 그 사진에 붙는다. ←/→는 놓인 사진 사이만 돈다. "표시 후 다음 사진"이 켜져 있어도 선택이 풀리지 않는다.
- [ ] ×를 누르면 그 칸이 빠지고 나머지가 다시 배치된다. 한 장만 남으면 "두 장 이상 선택하세요" 안내가 보인다. 칸을 두 번 누르면 사진 보기로 열린다.
- [ ] 13장 이상 선택하면 앞의 12장만 보이고 아래에 안내가 보인다.

## 보정 전·후 나눠 보기(Y)

- [ ] 노출을 올린 사진에서 Y → 사진 한 장이 흰 선으로 나뉘어 왼쪽 "보정 전"은 어둡고 오른쪽 "보정 후"는 밝다. 선이나 사진 위를 끌면 선이 따라온다.
- [ ] 크롭·회전한 사진에서도 두 쪽이 어긋나지 않고 겹친다. 슬라이더를 끄는 동안 오른쪽만 바뀐다.
- [ ] 나눠 보는 동안 사진 클릭은 100% 확대가 아니라 선 옮기기다. \나 100%를 누르면 나눠 보기가 잠시 사라지고 돌아오면 다시 보인다. Y를 다시 누르면 끝난다.

## 사진만 보기(F)

- [ ] 그리드에서 사진을 고르고 F → 사진 보기로 바뀌며 패널이 사라지고 전체 화면이 된다. 아래에 이름·별점·"F 또는 Esc로 나가기"가 보인다.
- [ ] 이 상태에서 ←/→, 0–5, P/X → 사진 이동과 표시가 된다.
- [ ] F 또는 Esc → 원래 창 크기로 돌아온다. 처음부터 전체 화면이던 창은 전체 화면을 유지한다.
- [ ] 사진만 보기에서 초록 버튼·⌃⌘F로 전체 화면을 끈다 → 사진만 보기도 끝난다.
- [ ] 창 상태에서 F를 빠르게 두 번 누른다 → 전환 애니메이션이 끝난 뒤 원래 창으로 돌아온다(전체 화면에 남지 않는다). 세 번 누르면 전체 화면 사진만 보기로 남는다.

## 오른쪽 클릭 메뉴·회전·Finder

- [ ] 그리드에서 두 장을 고르고 그중 한 장을 오른쪽 클릭 → 별점·표시·색상 라벨·폴더에 추가 하위 메뉴가 보이고, 고르면 두 장 모두 바뀐다. 고르지 않은 사진을 오른쪽 클릭해 고르면 그 사진만 골라 바뀐다.
- [ ] 필름 스트립·여러 장 보기 칸을 오른쪽 클릭 → 같은 메뉴가 뜨고 누른 사진에 적용된다.
- [ ] 오른쪽 클릭 › Finder에서 원본 보기(또는 ⌘R) → Finder가 원본 파일을 선택한 채 열린다. 원본이 없는 사진은 안내만 보인다.
- [ ] ⌘[·⌘] 또는 오른쪽 패널의 회전 단추 두 개 → 사진이 왼쪽·오른쪽으로 90°씩 돈다.

## 색상 라벨

- [ ] 그리드에서 세 장을 ⌘클릭으로 고르고 3·P·6을 누른다 → 세 장 모두 별점 3·선택·빨강이 되고 기준 사진은 그대로다. ⌘Z 한 번에 하나씩 되돌아간다. 사진 보기(E)에서 누르면 보고 있는 한 장만 바뀐다.
- [ ] 사진을 고르고 6 → 타일 별점 줄 오른쪽에 빨간 점, 필름 스트립 아래에 빨간 줄. 다시 6 → 사라진다. 7·8·9는 노랑·초록·파랑.
- [ ] 오른쪽 패널 라벨 줄에서 보라를 누른다 → 보라 라벨. 한글 입력 상태에서도 6–9가 동작한다. ⌘Z로 되돌아간다.
- [ ] 조건 단추 › 라벨에서 파랑 → 파랑 라벨 사진만 보인다.

## 키워드·설명

- [ ] 오른쪽 패널 키워드 칸에 `바다, 노을` 입력 후 Return → 검색창에 `노을`을 넣으면 그 사진만 보인다.
- [ ] 키워드를 입력하는 도중(Return 전) 다른 사진을 클릭한다 → 입력한 키워드는 처음 사진에 저장되고, 새 사진 칸에는 그 사진의 키워드가 보인다.
- [ ] 여러 장 선택 → "선택한 N장에 키워드 추가"에 입력 후 추가 → 각 사진에 붙고 ⌘Z 한 번으로 모두 되돌아간다.
- [ ] 검색창·키워드·설명 칸에 글자를 입력하고 ⌘Z / ⇧⌘Z → 입력한 글자만 되돌리고 다시 하며, 사진의 별점·보정은 바뀌지 않는다. 칸 밖에서 ⌘Z는 사진 변경을 되돌린다.
- [ ] 키워드를 Return으로 저장한 뒤 편집 메뉴의 실행 취소를 누르고 다른 곳을 클릭 → 키워드가 되돌아간 값으로 남는다.

## 자동 보정

- [ ] 사진 보기에서 빛 옆 "자동"(또는 ⌘U) → 잠시 표시가 돈 뒤 노출·색온도·틴트·하이라이트·섀도 슬라이더가 바뀌고 다른 보정은 그대로다. ⌘Z 한 번으로 돌아간다.
- [ ] 계산하는 동안 다른 사진으로 옮기면 적용하지 않았다는 안내가 보인다.
- [ ] 노을·실내 조명 사진에서 색이 지나치게 중립으로 가지 않는지 본다(색온도는 ±1500K까지만 옮긴다).

## 슬라이더 기본값

- [ ] 노출을 움직인 뒤 "노출" 글자나 값을 두 번 누른다 → 노출만 0.00 EV로 돌아가고 다른 값은 그대로다. ⌘Z 한 번으로 방금 값으로 돌아간다.
- [ ] RAW의 노이즈 감소를 움직인 뒤 두 번 누른다 → "자동 N%"로 돌아간다. HSL·필름 입자·부분 보정·LUT 강도 슬라이더도 같은 방식으로 돌아간다.

## 스냅숏과 보정 기록

- [ ] 오른쪽 패널 "스냅숏 · 보정 기록"을 펼치고 노출·대비를 바꾼다 → 기록에 "처음 상태", "노출", "대비"가 최신이 위로 쌓이고 현재 줄에 체크가 보인다.
- [ ] "노출" 줄을 누른다 → 그 상태로 돌아가고 새 줄이 생긴다. ⌘Z로 돌아가기 전으로.
- [ ] 이름을 넣고 "지금 상태 저장" → 스냅숏 목록에 생긴다. 보정을 바꾼 뒤 스냅숏을 누르면 그 상태로, 휴지통으로 지운다. 앱을 다시 열어도 스냅숏은 남고 기록은 비어 있다.

## HDR 하이라이트 (XDR 화면)

- [ ] RAW의 RAW 현상에서 HDR 하이라이트를 1로 올리고 노출을 +1.5 EV → 하늘·흰 벽 같은 밝은 부분이 화면 흰색보다 밝게 빛나고 중간 톤은 그대로다. 끄면 원래대로.
- [ ] 슬라이더를 끄는 동안은 SDR로 보이다가 놓으면 HDR로 돌아온다. 썸네일·히스토그램은 SDR이다.
- [ ] 내보내기 창에 "HDR 하이라이트를 쓴 사진은 HDR로 저장"이 보인다. JPEG·HEIF로 내보낸 파일을 미리보기 앱·사진 앱에서 열면 밝은 부분이 HDR로 보이고, HDR을 모르는 곳에서는 일반 사진으로 보인다. TIFF를 고르면 SDR로만 저장한다는 안내가 보인다.

## 보정 복사·붙여넣기

- [ ] 편집 메뉴에 "보정 복사 ⇧⌘C", "보정 붙여넣기 ⇧⌘V"가 보인다. 한글 입력 상태에서도 단축키가 동작한다.
- [ ] 여러 장 선택 후 ⇧⌘V → 모든 선택 사진에 전체 보정·LUT가 들어가고 크롭·부분 보정은 그대로다. ⌘Z 한 번으로 되돌아간다.

## 카탈로그에서 빼기

- [ ] 사진을 고르고 Delete → "…을 카탈로그에서 뺄까요?" 확인 창. 취소하면 아무것도 바뀌지 않는다.
- [ ] RAW+JPEG 한 장으로를 켠 상태에서 RAW를 빼기 → 확인 창에 "JPEG 1장도 함께" 문구. 뺀 뒤 두 파일 모두 Finder에 남아 있다.
- [ ] 내 폴더를 보면서 Delete → 확인 창 없이 그 폴더에서만 빠지고 전체 사진에는 남는다.
- [ ] 두 장을 카탈로그에서 뺀 뒤 ⌘Z → 원래 자리에 썸네일·별점·보정과 함께 돌아오고, 들어 있던 내 폴더에도 다시 보인다. ⇧⌘Z로 다시 빠진다.

## 끌어 놓기

- [ ] Finder에서 사진 폴더를 창으로 끈다 → 주황 테두리와 "놓으면 가져옵니다"가 보이고, 놓으면 가져온다. 원본은 그 자리에 남는다.
- [ ] 그리드에서 세 장을 선택하고 그중 하나를 왼쪽 내 폴더로 끈다 → 폴더 줄이 강조되고, 놓으면 세 장이 들어간다. 선택하지 않은 사진을 끌면 그 사진만 들어간다.
- [ ] 사진을 창 안의 다른 곳(가운데 그리드)에 놓는다 → 가져오기 안내가 뜨지 않고 아무 일도 없다.
- [ ] 사진을 창 밖(Finder 바탕화면·메모 앱)에 놓는다 → 받지 않는 표시로 돌아가고 텍스트 클리핑 같은 파일이나 글자가 생기지 않는다.
- [ ] 사진을 끄는 대신 누르기·⌘클릭·⇧클릭·두 번 누르기가 전과 같이 동작한다.

## 조건과 스마트 폴더

- [ ] 검색창 옆 조건 단추 → 표시·카메라·렌즈·초점거리·ISO·시작일·마지막 날을 고르면 목록이 바로 바뀌고, 단추가 주황색이 되며 제목 아래에 "N장 표시 · 조건 요약"이 보인다.
- [ ] 이름을 넣고 저장 → 왼쪽 스마트 폴더에 생기고 선택되며 같은 사진이 보인다. 조건 단추는 다시 회색이다. 다른 사진에 별점을 올려 조건에 맞추면 폴더 개수가 늘어난다.
- [ ] 스마트 폴더 … 메뉴에서 이름 변경·삭제 → 사진은 그대로다. 앱을 다시 열어도 스마트 폴더가 남는다.
- [ ] 조건 창의 시작일·마지막 날 칸에 날짜가 끝까지 보인다(창 밖에서 그린 화면에서는 "2026. 9. 27."의 끝이 잘려 보였다).

## 연속 촬영의 눈 감은 컷

- [ ] 사람이 찍힌 연속 촬영(한 컷은 눈 감음)에서 베스트 컷 분석 → 눈 감은 컷에 "눈 감음" 표시가 붙고, 더 선명해도 추천되지 않는다. 모든 컷이 눈을 감았으면 점수로 추천한다.

## 원본 없음과 위치 다시 찾기

- [ ] 앱을 켠 채 Finder에서 가져온 폴더 이름을 바꾸고 앱으로 돌아온다 → 타일에 주황색 "원본 없음", 왼쪽에 "원본 없음 (N)" 목록, 오른쪽 패널에 경로와 "위치 다시 찾기…".
- [ ] 그 상태로 앱을 끝냈다 다시 연다 → 원본 없는 사진의 타일에 이전 썸네일이 보인다. 위치를 다시 찾으면 썸네일이 새로 만들어진다.
- [ ] 위치 다시 찾기… → 바뀐 폴더(또는 그 상위 폴더)를 고른다 → 같은 폴더의 사진이 모두 다시 연결되고 표시가 사라진다.
- [ ] 외장 드라이브의 사진: 드라이브를 빼면 원본 없음, 다시 꽂으면 표시가 사라진다.

## 내보내기

- [ ] 내보내기 창 제목이 "내보내기"이고 형식(JPEG·HEIF (10비트)·TIFF (16비트))과 색 공간(sRGB·Display P3)을 고를 수 있다.
- [ ] TIFF를 고르면 품질 슬라이더 대신 "압축하지 않은 16비트… 약 140MB" 안내, 파일 이름 예시가 `.tif`로 바뀐다. 미리보기 아래 형식·크기가 표시된다.
- [ ] Display P3를 고르면 "옅게 보일 수 있어…" 안내가 보인다. 내보낸 파일을 미리보기 앱의 정보 보기로 열면 프로필이 Display P3다.
- [ ] 키워드를 붙인 사진을 내보내 미리보기 앱 정보(IPTC)에서 키워드·설명이 보인다.
- [ ] 저장 폴더를 고른 뒤 창을 닫고 다시 열면 같은 폴더가 선택되어 있다.
- [ ] 내보낸 사진의 노출을 바꾸고 내보내기 창을 연다 → 맨 위에 "보정이 바뀐 사진 1장"이 보이고 다시 내보내기로 같은 폴더에 새 파일(번호 붙음)이 생긴다. 휴지통 옵션을 켜면 이전 파일이 Finder 휴지통으로 가고 같은 이름으로 쓴다. 오른쪽 패널 파일 정보에 "내보냄 … · 그 뒤 보정 바뀜"이 보였다가 사라진다.

## XMP 사이드카

- [ ] 사진 메뉴의 "별점·키워드를 XMP 사이드카로 쓰기"를 켠다 → 별점·라벨·키워드가 있는 RAW 옆에만 `.xmp`가 생기고(표시 없는 RAW와 JPEG·HEIC 옆에는 없음) "XMP 사이드카 N개 씀" 안내가 보인다. 별점·라벨·키워드를 바꾸면 곧 파일이 바뀐다. Lightroom·Bridge에서 그 RAW를 열면 별점·라벨·키워드가 보인다.
- [ ] 카메라나 다른 앱이 만든 `.xmp`가 있는 사진, 또는 Lighthouse가 쓴 `.xmp`를 다른 앱(Lightroom 등)에서 고쳐 저장한 사진 → 덮어쓰지 않았다는 안내가 보이고 그 파일은 그대로다. 끄면 더는 쓰지 않는다(이미 쓴 파일은 남는다).

## 보관본과 오류 안내

- [ ] 파일 메뉴 › 카탈로그 보관본 보기 → Finder에서 `Backups` 폴더가 열리고 오늘 날짜 폴더가 있다. 자동 선택 마스크를 쓴 사진이 있으면 그 안에 `Masks` 폴더가 있다.
- [ ] 격리 카탈로그의 `catalog.json`을 일부러 깨뜨리고 실행 → 오류 화면에 보관본 경로와 복원 방법이 보인다. 앱은 깨진 파일을 덮어쓰지 않는다.
