# 폴더 관리와 원본 보존

왼쪽 **원본 위치**는 실제 사진 파일이 있는 폴더별로 라이브러리를 보여줍니다. **내 폴더**는 Lighthouse 안에서 만드는 관리 폴더입니다. 여행·날짜·작업별로 정리할 수 있으며 같은 사진을 여러 폴더에 넣어도 원본 파일은 하나로 유지됩니다.

1. **새 폴더…**를 누르고 이름을 입력합니다. 이미 사진을 선택했다면 그 사진들을 함께 넣을 수 있습니다.
2. 전체 라이브러리에서 사진을 여러 장 선택하고 **폴더에 추가**에서 폴더를 고릅니다.
3. 왼쪽 폴더를 누르면 해당 사진들만 보입니다. 폴더 관리 메뉴에서 이름을 바꾸거나 폴더를 삭제할 수 있습니다.
4. **이 폴더에서 빼기**는 선택한 사진의 폴더 소속만 해제합니다. 전체 라이브러리, 다른 폴더, 보정값은 유지됩니다.

폴더 삭제도 폴더 구성만 지웁니다. Finder의 파일을 이동·삭제하지 않습니다. 현재 버전의 내 폴더는 한 단계 구조이며 중첩 폴더는 제공하지 않습니다. 사진 가져오기는 전체 라이브러리에 등록하는 동작이므로, 가져온 뒤 원하는 폴더에 추가하세요.

모든 편집은 **비파괴 방식**입니다. 노출·색상·마스크·LUT·참조 색감의 보정값을 별도로 자동 저장하고 원본 RW2/JPEG는 그대로 둡니다. **원본 보기**로 보정 전 모습을 비교하고, **보정 초기화**로 현재 사진을 원래 상태로 되돌릴 수 있습니다. 초기화도 ⌘Z로 취소할 수 있습니다. 편집 결과는 **JPEG 내보내기**로 별도 저장하세요.

백업 대상은 `~/Library/Application Support/Lighthouse/`의 `catalog.json`, `folders.json`, `LUTs` 폴더와 실제 원본 사진입니다. 원본 파일을 Finder에서 이동하면 앱에서 읽을 수 없으므로 원래 위치로 복원해야 합니다.
