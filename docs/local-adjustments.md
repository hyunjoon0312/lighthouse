# 부분 보정

사진에서 밝게 하거나 대비를 바꾸고 싶은 부분을 브러시로 칠해 보정한다. 칠한 범위는 마스크로 저장되며 원본 파일은 바뀌지 않는다.

## 사용 순서

1. 사진을 선택하고 오른쪽 **부분 보정** 패널을 연다.
2. **영역 추가**로 새 영역을 만든다. 사진 위를 드래그하면 그 부분이 마스크에 추가된다. 한 번 클릭해 둥근 영역을 만들 수도 있다.
3. **브러시 크기**를 조절해 넓은 면이나 작은 부분을 칠한다. 크기는 원본 짧은 변에 대한 브러시 지름 비율이다. 잘못 칠한 부분은 **지우개**로 지운다.
4. **영역 노출**을 올리면 해당 부분이 밝아지고, **영역 대비**를 올리면 그 부분의 명암 차이가 커진다. **경계 부드럽게**(0–100)로 주변과 자연스럽게 이어지도록 조절한다.
5. **마스크 표시**를 끄고 실제 보정 결과를 확인한다. **그리기 완료**를 누르면 사진 위에서 칠하기를 마친다.
6. 다른 부분에 다른 보정을 적용하려면 영역을 추가한다. 목록에서 기존 영역을 선택해 다시 칠하거나 값을 바꿀 수 있다.

영역을 비활성화하면 설정과 칠한 범위를 남긴 채 효과만 끈다. 삭제하면 그 영역을 제거한다. 겹친 영역은 목록 순서대로 효과가 적용된다.

## 저장과 보기

- 한 번의 드래그는 실행 취소 한 번으로 되돌릴 수 있다. 보정값과 영역 변경도 기존 실행 취소·다시 실행을 사용한다.
- 영역은 카탈로그에 자동 저장된다. 앱을 다시 열면 보정값과 함께 복원된다.
- 회전·중앙 크롭을 바꿔도 칠한 위치는 원본 피사체를 따라간다.
- 브러시 입력은 **사진 보기 + 화면 맞춤 + 보정 보기**에서 제공한다. 100% 확대, 원본 보기, 비교·그리드로 전환하면 칠하기를 멈춘다. 부분 영역을 다시 선택하면 편집할 수 있다.
- JPEG 내보내기에는 전체 보정과 부분 보정이 함께 적용된다. 마스크를 보여주는 색이나 커서는 출력되지 않는다.

현재 기능은 직접 칠하는 브러시 마스크이다. AI 피사체·하늘 자동 선택이나 움직이는 영역 변형 도구는 제공하지 않는다.
