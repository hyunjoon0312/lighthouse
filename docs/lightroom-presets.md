# Lightroom 프리셋과 선별 작업

Lightroom에서 쓰던 `.xmp` 또는 `.lrtemplate` 현상 프리셋을 Lighthouse에 가져와 현재 사진과 여러 사진에 적용할 수 있습니다. 가져온 설정은 Mac의 프리셋 보관함에 저장됩니다.

## 가져와 적용하기

1. **Lightroom 프리셋 가져오기…**를 누르고 `.xmp`나 `.lrtemplate` 파일을 고릅니다. 여러 파일을 함께 선택할 수 있습니다. ZIP으로 받은 팩은 먼저 압축을 풉니다.
2. 가져오기 결과에서 추가된 프리셋과 제외된 설정을 확인합니다. 읽을 수 없는 파일이 섞여 있어도 나머지 파일은 따로 처리합니다. 같은 이름은 번호를 붙여 보관합니다.
3. 사진을 고르고 오른쪽 **전체 보정 → 프리셋**에서 이름을 누릅니다. 목록 위 검색으로 이름을 찾을 수 있습니다. 라이브러리의 **프리셋 적용** 메뉴에서도 적용할 수 있습니다.
4. 여러 장을 선택한 상태에서 적용하면 선택한 사진 각각에 적용되며 **⌘Z** 한 번으로 함께 되돌립니다. **가져올 때 적용**을 고르면 이후 새로 가져오는 사진에도 같은 프리셋을 적용합니다.

프리셋을 보관함에 추가하는 것만으로 사진이 바뀌지는 않습니다. Lightroom 프리셋에 지정된 항목만 바뀌므로, 노출만 담긴 프리셋을 적용해도 현재 채도나 크롭은 유지됩니다. 곡선도 채널별, HSL도 색상과 속성별로 적용합니다. 가져온 프리셋의 이름을 바꾸거나 앱을 다시 열어도 이 방식은 유지됩니다.

원본 사진과 프리셋 파일은 읽기만 합니다. 사진의 보정은 카탈로그에, 가져온 프리셋은 카탈로그 옆 `presets.json`에 저장합니다. 보관함에서 프리셋을 삭제해도 이미 사진에 적용한 보정은 유지됩니다.

## 호환되는 설정

Lightroom과 Lighthouse는 현상 엔진이 다릅니다. 같은 값이어도 색과 세기가 달라질 수 있으며, 가져온 프리셋의 **호환 정보**에서 적용 범위를 확인할 수 있습니다.

| 항목 | 적용 범위 |
| --- | --- |
| 노출·대비 | 앱 범위에 맞춰 변환. 노출은 ±4 EV까지 |
| 채도·생동감·명료도 | 지원하는 값으로 근사 변환 |
| 하이라이트·섀도·흰색·검정 | -100…100 양방향 조절. 기존 사진의 보정값은 유지 |
| 톤 곡선 | 전체 RGB 및 R/G/B 채널의 포인트 곡선. 최대 16점, 양 끝 x 좌표 필요 |
| HSL | 빨강·주황·노랑·초록·아쿠아·파랑·보라·마젠타의 색조·채도·명도 |
| 선명도·비네팅·입자 | 선명도 양, 크롭 후 비네팅 양, 입자 양·크기·거칠기 |
| 기본 프로필·흑백 | Default Color/Color → 기본 색상, Default Monochrome/Monochrome 및 ConvertToGrayscale → 색상/흑백 선택 |
| 컬러 그레이딩·분할 톤 | 그림자·중간톤·하이라이트·전체의 색조·채도·명도, 혼합, 균형. 옛 분할 톤 키도 같은 값으로 읽음 |
| 텍스처·디헤이즈 | -100…100을 Lighthouse 텍스처·디헤이즈로 근사 변환 |
| 카메라 프로필 | Adobe Color 등 Adobe Raw 프로필 6종, Adobe Standard, Camera …(RAW만), 크리에이티브 프로필(모든 사진)과 Look 양을 이 Mac에 설치된 프로필로 연결 |
| 캘리브레이션 | 그림자 틴트, 빨강·초록·파랑 원색의 색조·채도 |
| 화이트밸런스 | RAW: 촬영 시·이름 있는 값·켈빈/틴트를 기준값으로. JPEG 등: 증분 색온도(×25 K)·틴트. 자동은 적용하지 않음 |

현재 흑백 믹서, 렌즈 보정, Adaptive 프로필과 설치되지 않은 Look, Adobe AI 마스크는 변환하지 않습니다. 이 설정이 포함되면 제외 항목으로 안내합니다.

화이트밸런스는 사진마다 적용 방식이 다릅니다. Lightroom처럼 RAW에는 켈빈 값, JPEG·HEIC에는 증분 값만 씁니다. 그래서 RAW와 JPEG를 함께 골라 적용하면 두 사진이 서로 다른 값을 받습니다. 켈빈 값은 macOS RAW 현상의 색온도 척도로 그대로 옮기며, Adobe와 색이 다를 수 있다는 안내를 붙입니다. 부분 보정·복구·크롭·LUT도 Lightroom 프리셋에서 가져오지 않습니다.

기본 프로필은 Lighthouse의 색상/흑백 처리로 연결합니다. RAW의 기본 색상은 macOS 현상 엔진을 따릅니다. `Adobe Color` 같은 Adobe Raw 프로필, `Adobe Standard`, `Camera Vivid` 같은 Camera Matching 이름, 프리셋의 `Look`(예: B&W 01, 양 150%)은 Camera Raw가 이 Mac에 설치한 프로필 파일을 찾아 근사 적용합니다. 프로필이 없는 Mac에서는 프로필 없이 보입니다. 매핑한 프로필에도 엔진 차이 안내를 표시합니다.

이전 버전에서 가져온 프리셋은 제외된 숫자를 저장하지 않았습니다. **새로 지원하는 항목을 적용하려면 원본 XMP/lrtemplate을 다시 가져오세요.** 같은 이름은 중복을 피하도록 새 이름으로 보관됩니다.

Adobe Look·전용 프로필 파일, DNG에 담긴 모바일 프리셋, ZIP 팩은 직접 읽지 않습니다. 일반 XMP 프리셋이 기본 색상/흑백 프로필만 지정하는 경우는 지원합니다. 파일당 2 MiB 이하의 UTF-8 텍스트를 지원합니다. 지원하는 설정이 하나도 없는 파일과 잘못된 수치·문법은 오류로 알려 줍니다. `.lrtemplate`은 데이터만 읽으며 Lua 코드를 실행하지 않습니다.

## 새 조절값 사용하기

오른쪽 **빛**에서 하이라이트·섀도·흰색·검정을 -100…100으로 조절합니다. 0은 중립이며, 이름이나 값을 두 번 누르면 해당 항목만 기본값으로 돌아갑니다. **색상 → 프로필**에서 기본 색상과 흑백을 선택합니다. **필름 입자 → 거칠기**는 0…100, 기본값은 50입니다. 입자 양이 0이면 거칠기 변화는 보이지 않습니다.

**색상 → 컬러 그레이딩**에서 그림자·중간톤·하이라이트·전체 중 하나를 고르고 바퀴를 끌어 색조와 채도를 정합니다. 명도는 해당 밝기대만 밝히거나 어둡게 합니다. 혼합은 영역 경계의 부드러움, 균형은 그림자와 하이라이트의 경계 위치입니다. 흑백 프로필과 함께 쓰면 분할 톤 흑백 사진을 만들 수 있습니다. 색 변환은 Lighthouse 고유 수식이며 Adobe 결과와 같은 픽셀을 보장하지 않습니다.

`my.slow.film`을 다시 가져오면 흰색 -17, 검정 -27, 섀도 -2, 입자 거칠기 50이 포함됩니다. Default Color는 기본 색상으로 연결되며, RGB 곡선·입자와 함께 실제 S9 RAW 및 JPEG 출력까지 확인했습니다. [추가 검증 기록](lightroom-tone-verification.md)에서 확인 범위를 볼 수 있습니다.

## 선별하고 보정하기

라이브러리의 빠른 표시 필터로 **전체 표시·채택·미분류·제외**를 전환합니다. 미분류는 아직 P/X 표시를 붙이지 않은 사진입니다. 별점·검색·현재 폴더 조건과 함께 적용되고, **전체 표시**는 표시 필터만 해제합니다.

- **P**: 채택, **X**: 제외, **U**: 표시 해제. 제외 표시는 원본 파일을 삭제하지 않습니다.
- **0–5**: 별점. **표시 후 다음 사진**을 켜면 한 장을 표시한 뒤 다음 사진으로 넘어갑니다.
- **G**: 그리드, **E**: 사진, **C**: 비교, **N**: 선택한 여러 장 보기. **F**: 사진만 보기.
- **⌘클릭·⇧클릭**으로 여러 장을 고른 뒤 프리셋을 적용하거나, 필요한 항목만 **일괄 적용…**으로 옮깁니다.
- 자주 쓰는 검색·별점·카메라·렌즈 조건은 **스마트 폴더**로 저장합니다. 수동 묶음은 **내 폴더**에 모읍니다.

프리셋 적용 후 노출·색온도·곡선·HSL을 다듬고, 필요하면 기존 마스크·복구·크롭 기능을 이어서 사용합니다. 같은 사진의 여러 색감을 비교하려면 **가상 사본 만들기(⌘')**로 보정만 분리합니다.

형식 참고: [Adobe 프리셋 가져오기](https://www.adobe.com/learn/lightroom-cc/web/import-presets), [Camera Raw XMP 명세](https://developer.adobe.com/xmp/docs/xmp-namespaces/crs/). 이 앱의 수치 변환은 Adobe 엔진을 복제한 것이 아닙니다.

추가 톤·입자·기본 프로필의 저장·렌더 규칙은 [개발 계약](lightroom-tone-contract.md)에 있습니다.
