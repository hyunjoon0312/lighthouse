# 플리커·마스크·오프라인 사진 작업

모든 보정은 카탈로그에 저장되며 원본 사진 파일을 바꾸지 않습니다.

## 플리커 띠 보정

전자셔터와 깜박이는 조명 때문에 생긴 규칙적인 밝기·색 띠를 줄이는 기능입니다. 전체 보정 패널의 **플리커 띠 보정**에서 **띠 자동 분석**을 누르면 사진의 가로·세로 밝기 패턴을 분석합니다. 분석한 결과를 적용한 뒤 강도를 조절하고, 필요하면 방향·반복 횟수·위상·진폭을 다듬습니다. **색 띠**는 채널마다 다른 색 띠를 줄이는 정도입니다.

분석이 실패하면 기존 보정값을 유지합니다. 일정한 벽 무늬나 블라인드를 조명 띠로 오인할 수 있으므로 보정 전·후를 비교하세요. 규칙적이지 않은 띠, 서로 다른 조명이 섞인 장면, 이미 하얗게 날아가거나 검게 뭉개진 부분은 완전히 복원되지 않을 수 있습니다. 분석 결과의 신뢰도는 정확도를 보장하는 확률이 아닙니다.

이 보정은 사진 한 장의 규칙적인 패턴을 추정합니다. 촬영 시 S9의 셔터 설정으로 줄일 수 있는 플리커를 모두 사후 복원한다는 뜻은 아닙니다. 실제 플리커가 있는 S9 촬영 표본의 화질 검증 여부는 [사진 작업 확장 검증 기록](workflow-verification.md)에 별도로 남깁니다.

## 밝기·색으로 부분 영역 선택

**부분 보정**에서 **밝기 범위** 또는 **색상 범위**를 고릅니다. 밝기 범위는 어두운 곳부터 밝은 곳까지 선택할 구간을, 색상 범위는 기준 색과 허용 범위를 정합니다. 경계의 부드러움도 조절할 수 있습니다.

선택 영역은 보정 전 사진의 색·밝기를 기준으로 생성해 저장합니다. 이후 노출이나 LUT를 바꿔도 영역이 자동으로 바뀌지 않습니다. 범위를 바꾸려면 **범위 다시 설정**을 사용하고, 브러시·지우개로 더하거나 뺄 수 있습니다.

각 부분 영역의 **영역 노이즈 감소**에서 **일반 / AI**와 강도를 정할 수 있습니다. 예를 들어 배경 영역의 노이즈만 줄이거나, 밝기 범위로 어두운 부분을 골라 처리할 수 있습니다. AI 모델은 앱에 포함되어 Mac에서 실행합니다. 영역들이 겹치면 뒤쪽 영역의 결과가 우선합니다. 전체 노이즈 감소를 함께 켜면 전체 처리 결과를 바탕으로 부분 영역을 추가 처리합니다.

## 여러 사진의 피사체·배경 다시 인식

**일괄 적용…**에서 부분 보정을 선택하고 **사진마다 피사체·배경 다시 인식**을 켭니다. 새로 만든 피사체·배경 영역은 각 대상 사진에서 다시 찾은 모양에 원래 보정값을 적용합니다.

이전 버전에서 만든 자동 영역은 피사체인지 배경인지 기록되지 않았으므로 재인식 대상이라고 추측하지 않습니다. 필요한 경우 새로 피사체·배경 영역을 만드세요. 직접 그린 브러시와 복구 위치는 원래 좌표를 복사합니다. 사람이 움직인 위치에 맞춰 브러시까지 이동하는 기능은 아닙니다.

분석하지 못한 사진은 그 사진의 일괄 변경을 건너뛰고 결과에 표시합니다. 작업을 취소하면 계산 중이던 보정을 적용하지 않습니다. 완료한 일괄 보정은 한 번의 실행 취소로 되돌릴 수 있습니다.

## 중복·유사 사진 찾기

**사진 → 중복·유사 사진 찾기…**를 엽니다. 두 장 이상을 선택했다면 그 선택을, 그렇지 않으면 현재 보이는 목록을 분석합니다.

- **동일 파일** 후보는 파일 전체 내용의 해시가 같은 서로 다른 원본 경로입니다. 같은 원본을 공유하는 가상 사본은 중복으로 세지 않습니다.
- **유사 사진** 후보는 보정 전 썸네일의 모양·색·비율을 비교한 결과입니다. 사진 의미나 인물의 동일성을 판정하는 기능은 아닙니다.

**이 묶음 비교**를 눌러 여러 장 보기에서 직접 선별합니다. 검색은 원본을 지우거나 선택·제외 표시를 자동으로 붙이지 않습니다. 읽지 못한 파일이 있어도 다른 사진을 계속 분석하고 실패 항목을 따로 표시합니다.

## 원본 없이 기본 보정 이어가기

외장 드라이브를 빼기 전에 사진을 선택하고 **사진 → 스마트 미리보기 관리…**를 열어 **만들기**를 누릅니다. 중립 보정의 긴 변 최대 2560픽셀, 16비트 sRGB TIFF가 라이브러리의 `SmartPreviews` 폴더에 저장됩니다. 디스크 공간이 필요하며 원본의 백업을 대신하지 않습니다.

원본이 없을 때 유효한 스마트 미리보기가 있으면 **스마트 미리보기 · 원본 없음 · 기본 보정 근사**가 표시됩니다. 노출·색·LUT·기존 부분 영역의 기본 효과·구도 보정을 이어갈 수 있습니다. 변경값은 원래 사진의 카탈로그에 저장되므로 원본을 다시 연결하면 원본에 적용됩니다.

스마트 미리보기로는 원본의 100% 디테일이나 RAW·AI 노이즈 감소 결과를 판단할 수 없습니다. 플리커 분석, 새로운 자동·범위 마스크 생성, 복구 작업, 최종 고해상도 내보내기에는 원본이 필요합니다. 기존에 저장한 노이즈 감소·플리커 등의 값은 유지하지만 오프라인 근사 화면에서는 적용하지 않습니다. 원본이 있는데 읽기 오류가 난 경우도 스마트 미리보기로 오류를 숨기지 않습니다.

원본을 다른 위치로 재연결하거나 파일 내용이 바뀌었다면 스마트 미리보기를 다시 만드세요. 필요 없어지면 같은 관리 창에서 **삭제**를 눌러 저장 공간을 돌려받을 수 있습니다.

## 전체 백업과 새 Mac 복원

1. **파일 → 라이브러리 백업…**에서 새 백업 위치를 고릅니다. 새 Mac으로 원본까지 옮기려면 **원본 사진 포함**을 켭니다. 원본이 하나라도 누락되어 있으면 전체 포함 백업은 완료되지 않습니다. 드라이브를 다시 연결하거나 원본 미포함 백업을 선택하세요.
2. 생성한 `.lighthousebackup` 폴더 전체를 새 Mac이나 별도 드라이브로 복사합니다. 안의 파일 이름이나 내용을 바꾸지 마세요. 앱 파일은 별도로 설치합니다.
3. 새 Mac의 **파일 → 라이브러리 복원…**에서 백업을 선택하고 복원본을 둘 상위 폴더를 고릅니다. 앱이 그 안에 새 폴더를 만들어 파일 무결성과 카탈로그를 검사하며 복원합니다. 완료 후 **복원한 라이브러리 열기**를 누릅니다. 원본 포함 백업이면 원본 파일명을 유지하며 새 위치로 연결합니다. 서로 다른 폴더에 있던 같은 이름의 사진도 별도 하위 폴더에 복원됩니다.
4. 사진·폴더·별점·사람 분류·보정·LUT를 확인하고 한 장을 내보내 봅니다. 기존 라이브러리는 보존되며 **파일 → 라이브러리 열기…**로 다시 열 수 있습니다. 두 라이브러리를 합치는 기능은 아닙니다.

백업에는 카탈로그, 내 폴더·스마트 폴더, 프리셋, 사람 분류, LUT, 마스크, 스마트 미리보기와 선택적으로 원본이 들어갑니다. 썸네일 캐시·이전 자동 보관본·Google 로그인 인증 정보·Mac 화면 환경설정은 제외합니다. Google Drive는 새 Mac에서 다시 연결하세요. 기존 내보내기 파일도 따로 옮겨야 합니다. 복원한 라이브러리는 예전에 내보낸 파일을 교체하는 권한을 이어받지 않습니다.

원본 미포함 백업은 예전 사진 경로를 유지합니다. 새 Mac에서 사진 폴더를 별도로 옮긴 뒤 **사진 → 위치 다시 찾기…**로 연결하세요. 매일 생성하는 `Backups`는 원본과 LUT를 포함하지 않는 간단한 카탈로그 보관본이며, 위 전체 백업과 별개입니다.
